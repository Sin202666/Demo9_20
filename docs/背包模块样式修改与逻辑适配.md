## 1. 先分清三件事

| 你要做的 | 改哪里 | 不要做 |
|----------|--------|--------|
| **换皮 / 排版 / 动效外观** | Place 里 `ScreenGui.Main.Backpack` 子树（颜色、尺寸、锚点、布局、字体） | 改 `Name`、Class、删必备节点；代码里 `Instance.new` 整窗 |
| **格子里图标/数量长什么样** | 工具栏 / 仓库的 **Temp** 模板（与奖励格同一套 `SetAward` 子节点名） | 在 GuiScripts 里手写 `ImageLabel.Image` |
| **谁能进仓库、谁能上快捷栏、几个槽、容量条** | `GetData.BagCapacity` 闭集 + `GameConfig.背包配置` | 在 UI 写死 `UseItem` / `Pet`；客户端改 `PlayerData.Bag` |

**硬边界（P0）：**

- 物品增减、锁定、`Bag.equip` **只在服务端**（`SystemBag` / `BagEquip`）。
- 客户端只渲染 + 发 Remote + overlay 预测；禁止 `PlayerData.ChangePlrData`。
- 发奖默认 `Capacity.None`：**UI 满仓不等于服务端会拦**。商店/邮件/签到入包不走窗口上限。

## 3. Place 节点约定（样式修改的合同）

路径均相对 `ScreenGui.Main`。`AllUI.collect` **按 Name + Class** 取节点；名称或类型不对 = 收集失败或功能静默跳过。

### 3.1 必备（缺一则背包 HUD 起不来）

```
Main
└── Backpack                    Frame
    ├── 工具栏                  Frame
    │   └── Temp                GuiObject（Frame 或 GuiButton）  -- 快捷栏格子模板，运行时克隆
    └── 仓库                    Frame
        └── ScrollingFrame      ScrollingFrame
            └── Temp            GuiObject                        -- 仓库格子模板，运行时克隆
```

启动脚本：`StarterPlayerScripts/ClientScript/InitBackpack.client.luau`。  
缺 `Main.Backpack` 会打日志并在 `CharacterAdded` 再试一次，**不会代码生成整窗**。

### 3.2 强烈建议（有则启用对应功能）

| 节点 | Class | 作用 |
|------|--------|------|
| `仓库.容量.Size` | TextLabel | 容量条 `used/max`（`SetRawText`，不走翻译表） |
| `仓库.搜索` 下任意 TextBox | TextBox | 译名搜索 |
| `仓库.页签` | Frame | 页签容器 |
| `仓库.页签.All` | Frame | 「全部」（Window 全集） |
| `仓库.页签.Potion` | Frame | 全部 `UseItem`；Name 必须是 `BagCapacity.Tab.Potion` |
| `仓库.页签.Material` | Frame | `ItemType.Item`；Name 必须是 `BagCapacity.Tab.Material` |
| `仓库.锁定` + 四个子 Frame | Frame | 见 §3.3 |
| `仓库.拖动替换区` | Frame | 收集但不强制；栏→仓卸下主要看指针是否落在仓库格/开仓空白 |

### 3.3 锁定区（整组要齐，否则锁定功能跳过）

```
仓库.锁定                    Frame
├── 锁定状态                 Frame   -- 平常显示，点进锁定模式
├── 锁定全部                 Frame   -- 仅锁定模式显示
├── 解锁全部                 Frame
└── 回退                     Frame
```

四个子 Frame 少一个：打 warn，**工具栏和仓库网格仍可用**。  
根上若有 `UIListLayout`，进出锁定模式会改 `HorizontalAlignment`（平常 Right，模式中 Left）。改布局时把这个行为算进去，或接受被代码改对齐。

### 3.4 点击 / 拖拽热区

格子或页签必须满足 **之一**：

1. 根就是 `GuiButton`（ImageButton / TextButton），或  
2. 子级 **Name = `Button`** 且为 `GuiButton`

否则 `findSlotButton` 失败：该格不能点、不能拖。改样式时不要把按钮改成纯 `Frame` 又不起名为 `Button`。

### 3.5 只改样式、不必动代码

可以自由改（保持 Name / Class / 父子关系）：

- `Size` / `Position` / `AnchorPoint` / `LayoutOrder` / `ZIndex`
- `BackgroundColor3`、`UIStroke`、`UICorner`、`UIGradient`、`UIPadding`
- 字体、字号、`TextColor3`（**玩家可见句仍须走翻译**，见 §7）
- `UIListLayout` / `UIGridLayout` 间距（仓库滚动列表会在刷新后 `SetUIlistSize_New`）
- Temp 上装饰性子节点（只要不占用 §4 保留名，或占用后仍能被 `SetAward` 找到）

**不要改：** 上表中的中文/英文 **Name**、必备 Class、`Temp` 这个名字、页签 Frame 的 `UseItem` 等类型键名。

## 4. 格子模板（Temp）长什么样

工具栏 Temp 与仓库 Temp **建议同一套子节点**，因为两边都走 `UIMgr.BagSlot.AwardStyle` → `UIMgr.SetAward`。

### 4.1 `SetAward` 会找的子节点（有则填，无则跳过）

| Name | 典型 Class | 用途 |
|------|------------|------|
| `Icon` | ImageLabel | 物品图标 |
| `Count` | TextLabel | 数量 |
| `ZhName` | TextLabel | 译名（配置 `ZhName` 键） |
| `ViewportFrame` | ViewportFrame | 3D 预览 |
| `RoleIcon` | Frame | 英雄角色图标容器 |
| `ShardIcon` | ImageLabel | 碎片 |
| `ReqLv` / `LevelStr` | TextLabel | 等级类 |

空格时 `BagSlot.Clear` 会把上述节点 **Visible = false**，不要依赖它们常驻显示装饰。装饰请用别的 Name。

### 4.2 Core 额外认的子节点（背包专用）

| Name | 作用 |
|------|------|
| `已标记` | 锁定标记；`Visible = (lock == Locked)` |
| `选中` | 快捷栏当前数字键高亮槽 |
| `Number` | 快捷栏槽号，`SetRawText("1".."N")`；仓库格会藏 |

### 4.3 克隆行为（改 Temp 前必读）

- 运行时 `Temp:Clone()`，仓库克隆名为 `Warehouse_<onlyID>`，工具栏为 `Slot1`…`SlotN`。
- 克隆后会去掉树上残留的 **`代码本地化`** 标签，避免改名后被翻译管理器冲掉可变后缀。
- **不要**在 Temp 上依赖「模板里写死的中文 + `代码本地化`」当正式文案；格子文案走 `SetAward` / 配置 `Zh*`。
- 仓库只克隆 **当前筛选结果**；Temp 本身应 `Visible = false`（代码会关）。

工具栏槽数来自配置，**Place 里不必摆 8 个槽**，摆一个 Temp 即可。

## 5. 逻辑适配 cookbook

### 5.1 改快捷栏槽数（1~9）

1. 改 `src/ReplicatedFirst/AllSideCode/ToolBasic/GameConfig.luau`：

```lua
GameConfig["背包配置"] = {
	["窗口上限"] = 100,
	["工具栏快捷槽数"] = 8, -- 改这里；代码会钳制到 1~9
}
```

2. Place **不用**手摆 N 个槽；确认 `工具栏.Temp` 存在。  
3. 数字键高亮走 `SystemInput.ToolbarSlotActionId(i)`，槽数变化后 Core 会按 N 绑定。  
4. **V1 数字键只高亮，不使用物品。** 使用消耗品仍走既有 `UseItem` 服务端路径，不要在 Gui 里扣数量。

### 5.2 改仓库容量条上限

- 展示：`GetData.BagView.Occupancy(..., Capacity.Backpack)`，上限读 `背包配置.窗口上限`。  
- 占用：只计 `Filter.Window`（可叠按 `count`，其余一行 1），**含已上快捷栏的 Window 行**。  
- 服务端入包是否拦截：仅当调用 `AddItems(..., { capacity = "Backpack" })`。  
- `GRANT_AWARD` / 商店 / 邮件 **不传 opts** → `Capacity.None` → **不会因 UI 满而失败**。

若产品要求「满仓不发奖」，要改**发奖调用方**传 `capacity`，不要只改 UI。

### 5.3 新物品类型要出现在仓库页签

页签与 ItemType **不是**一对一。Place Frame.Name 对齐 `BagCapacity.Tab`（当前 `All` / `Potion` / `Material`），类型集在 Tabs 闭集里。**禁止在 Core 写死 `if tab == "Potion"`**。

现表：

| Tab（= Frame.Name） | 类型 | 文案 Key |
|---------------------|------|----------|
| `All` | `Filter.Window` 全集 | `背包页签-全部` |
| `Potion` | 全部 `UseItem` | `背包页签-药水` |
| `Material` | `Item` | `背包页签-材料` |

加页签：

1. 类型已在 `EnumMgr.ItemType`（不要为页签名新增 `Potion` / `Material` 枚举）。  
2. 若该类型要进仓：`FILTER_TYPES[Filter.Window]` 加上枚举值。  
3. `BagCapacity.Tab` + `TAB_ORDER` / `TAB_TYPES`：页签 id → 类型集（`All` 不进 `TAB_TYPES`）。  
4. Place：`仓库.页签.<TabId>` Frame。缺节点 = 该页签不出现，不会报错崩窗。  
5. `Backpack/Core.luau` 的 `_setTabLabel`：为新 Tab 加一支 **`SetText(label, "字面量Key")`**（禁止 `KEYS[tabId]`）。  
6. 同一改动写入 `config/Localization/LocalizationTable.xlsx`（zh-cn + en-us），提交打表。不要手改 `Language.luau`。

材料可进仓、计入容量条、可被 lockAll 扫到；**不能**上快捷栏（`Filter.Toolbar` 仍仅 `UseItem`）。

### 5.4 让某类物品能上快捷栏 / 自动上栏

默认 **只有 `UseItem`** 在 `Filter.Toolbar`。

1. `FILTER_TYPES[Filter.Toolbar]` 加上类型。  
2. 服务端 `BagEquip.SetEquip` / `SystemBagToolbar` 已读同一张表，无需再写一份白名单。  
3. 客户端 `View.canDropOnToolbar` 同样读这张表；非 Toolbar 类型拖到栏 **不会发 Remote**。  
4. **不要**在拖拽里召唤坐骑 / 宠物出战；`equip` ≠ 出战。出战仍走 Mount / Pet 自己的 System。

### 5.5 改锁定交互外观

- 平常：只显示「锁定状态」；锁定全部 / 解锁全部 / 回退隐藏。  
- 锁定模式：隐藏页签与「锁定状态」，显示另外三个。  
- 单击格子发 `BAG_LOCK_ITEMS` 单条；锁定全部只发 `{ mode = EnumMgr.BagLockMode.LockAll }`，**不要改成把 onlyID 全表交给客户端拼**。  
- overlay 是预测；权威以 `PLAYER_DATA_SYNC` 为准。关闭仓库会退出锁定模式，**不撤销已成功的服务端锁定**。

### 5.6 拖拽手感

| 项 | 位置 | 说明 |
|----|------|------|
| 拖动阈值 | `Drag.luau` `DRAG_THRESHOLD_PX = 12` | 小于阈值当点击 |
| 虚影 | 克隆源格，黄描边，ZIndex 1000 | 可改描边颜色/厚度 |
| 栏↔栏 | `SwapToolbarSlots` | 空槽视为把对方卸到该槽 |
| 栏→仓 | `SetEquip(..., 0)` | 开仓时拖到仓库空白也视为卸下 |
| 仓→栏 | 须 `Filter.Toolbar` | 宠物/蛋/坐骑默认拒绝 |
| overlay 超时 | `View.luau` `OVERLAY_ROLLBACK_SEC = 2` | 服拒绝或同步过慢会回滚显示 |

客户端不得在拖拽时写 `Bag.equip`。

### 5.7 开关仓库（顶栏按钮）

Core 监听玩家下 Bindable **`ToggleBackpackWarehouse`**。顶栏或热键只要：

```lua
InsMgr.GetIns("ToggleBackpackWarehouse", "BindableEvent", LocalPlayer):Fire()
```

不要复制一套显隐逻辑。仓库关闭时快捷栏 **只显示已装备的槽**；打开仓库后空槽也会显示以便拖入。

### 5.8 换格子皮肤（不再用奖励格）

V1 固定 `UIMgr.BagSlot.AwardStyle`。若快捷栏要 HUD 风、仓库要奖励风：

1. 在 `UIMgr/BagSlot.luau` 新增 style 表（`Bind` / `Clear`），**不要**做全局 `SetStyle`。  
2. `Core._bindSlot` 按工具栏/仓库传入不同 style。  
3. 新 style 仍只读 `BagView.ToSlotVM`，不写存档。

## 6. 文案与本地化

代码里已经绑定的 Key（改译文只改 Excel，Key 不要改除非同步改 `SetText` 字面量）：

| Key | 用途 |
|-----|------|
| `背包页签-全部` / `-药水` / `-材料` | 页签（`All` / `Potion` / `Material`） |
| `背包页签-消耗品` / `-宠物` / `-宠物蛋` / `-坐骑` | 旧页签 Key，本窗不再绑；可留在表里 |
| `锁定状态` / `锁定全部` / `解锁全部` / `回退` | 锁定区 |

容量数字、槽号用 `SetRawText`。搜索用 `TranslateByKey(cfg.ZhName)`，失败 **不回退中文键**。

静态装饰字：Place 实例打 CollectionService 标签 **`本地化`**，且 **Name = Key**。列表克隆不要依赖模板上的 **`代码本地化`**。

## 7. 禁止项（改样式时最容易踩）

| 禁止 | 原因 |
|------|------|
| 客户端改 `PlayerData.Bag` / 本地 `count++` | 刷物、与服不同步 |
| UI 里写死 `if tp == Potion` | 与闭集表分叉；加类型要改 `BagCapacity` |
| `SetText(label, keys[tabId])` | 本地化扫描要求调用处字面量或配置 `Zh*` |
| 手改 `Language.luau` / `ConfigInstance.luau` | 打表产物 |
| 拖宠物上栏当「出战」 | `equip` 只表示快捷栏槽；出战走 Pet/Mount |
| 用客机满仓结论拦发奖 | 发奖默认不检仓；要拦改服务端 `AddItems` 的 `opts.capacity` |
| 删除 `Temp` 或改名为 `Template` | `collect` 失败，整窗不启动 |
| 页签 Name 写成中文「药水」或 `UseItem` | 对不上 `BagCapacity.Tab.Potion` |

## 8. 改完怎么验

**只改 Place 样式：**

- [ ] 进游戏能看到快捷栏；开仓库能看到网格  
- [ ] 输出里没有 `Main.Backpack 缺失` / `slot button missing` / `Temp / ScrollingFrame 缺失`  
- [ ] 空格装饰还在；有物品时 Icon/Count 正常；锁定时「已标记」显隐对  
- [ ] 切语言后页签/锁定按钮不是 `未本地化-…`  
- [ ] 克隆出来的仓库格 Name 已是 `Warehouse_*`，翻译没有把数量后缀冲掉  

**改了槽数 / Filter / 容量：**

- [ ] 快捷栏克隆数量 = 配置 N  
- [ ] 非 Toolbar 类型拖到栏：客机无位移、服日志 refuse  
- [ ] UseItem 拖栏、栏内互换、卸回仓库后，换端或重进存档一致  
- [ ] 容量条数字与 `Occupancy` 一致；确认发奖是否仍不拦仓（产品预期）

**改了节点 Name：**

- [ ] 同步改 `AllUI.luau` 的 `_childOfClass(..., "旧名")`  
- [ ] 锁定四个子节点要么全有要么整组去掉

## 9. 最小对照：视觉 vs 逻辑

```
想换背景图 / 圆角 / 间距     → 只改 Place
想改格子图标框大小           → 改 Temp，保留 Icon 等 Name
想加「材料」页签             → 已有 Tab.Material = Item；Place 节点名必须是 Material
想加新页签                   → BagCapacity.Tab + Window（如需进仓）+ 页签 Frame + SetText 字面量 + Excel
想让宠物蛋上快捷栏           → BagCapacity.Toolbar（并确认不是出战）
想 6 格快捷栏                → GameConfig 工具栏快捷槽数
想满仓不发邮件附件           → 发奖 System 调 AddItems 时传 capacity，不是改 UI
```
