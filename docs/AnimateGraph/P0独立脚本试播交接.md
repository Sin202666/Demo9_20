## 3. 图内约定（Studio 已踩坑）

- Polar 绿针叫 **Angle / Magnitude**，不是 X/Y（Cartesian 才是 X/Y）。
- **Angle 在 Studio 里是角度。** 官方文档曾写 radians，以编辑器为准。
- 四向采样（Magnitude 均为 1）：Forward `0`、Right `90`、Back `180`、Left `-90`。曾误填 1.57/3.14 当弧度，会贴在「前」附近。
- Polar 图的屏幕「上」≠ 角色「前」。看十字靠近哪颗采样点、该点绑哪条 Clip。
- StartWalk/StartRun/StopRun/StopWalk：`OnceAndHold`。
- **StopWalk 已接 Select**（产品要保留）。现网 `AnimateSetting.TransitionEnable.StopWalk = false`，脚本暂不写 `StopWalk`；针空接即可。
- 过渡写在 Select 上，**不是绿参数**：`Default Transition Duration=0.18` Linear。Override 是「切进该针」的时长，没有 from→to 边。`Land→Walk 0.08` 图做不到，仍归脚本。
- 一个参数可接到多个 Speed：从已有 `ClipSpeed` 绿节点拖向第二、第三个 Speed，不要再 Add Parameter。
- `RunBack` 与 `WalkBack` 共用 AssetId `91745560081619`（`Animation.luau` 原样）。

Clip 表见 `LocoDefault.graph.json` → `clips`。

## 4. 和现 Animate 的关系（勿混）

| 层 | 谁做 |
|---|---|
| 姿态混合 / 选片 | 图（本 Spike 验证） |
| 状态编译（停步防抖、落地锁、SkipStart、ClimbAssist 压 Run→Walk） | 仍 `GroundLocomotion`；Spike 可先硬编码 `LocoState` |
| 位移 / WalkSpeed / HRP 偏航 | `CharacterMoveSpeed` / `CharacterMotion` / ShiftLock RenderStep，**禁止图脚本写** |
| 程序 lean | `AirLean` Stepped 写 RootJoint，不进图 |
| 技能 Overlay | `AnimationLayer`，不进 loco 图 |
| Gate pause | 现 Animate：`stopBaseAction`。Spike 若叠两条基轨会打架，见 §5 |

商业流：图出姿态，脚本出状态与写口。技术动画维护图，程序维护 `SetParameter` 契约。

## 5. Spike 实现约束

1. **不要改** `Animate/init.client.luau`、`AnimateModule`、`GroundLocomotion`、`StrafeBlend`。
2. 同一 Animator 上现 Animate 仍在播基轨 → 会叠姿。试播须二选一（写进方案）：
   - 临时 `Animate:stopBaseAction()`（或等价暂停），离开 Spike 时 `resume` + `invalidateBasePose` + `resyncAfterBaseUnpause`；或
   - 仅在实验室角色上关掉 Animate 脚本。
3. §1.7：Spike **不写** `HRP.CFrame` / `WalkSpeed` / `Store.cframe`。只 `SetParameter`。
4. 无新 Remote。本地玩家 Automatic 权威下客户端 `SetParameter` 即可（官方文档对旁观复制另有一套，P0 不做）。
5. 文件头 `Author` = `git config user.name`；UTF-8 无 BOM、LF。
6. 若上升为正式 System / 改 Animate：先方案再 §1.8，本 Spike 不要顺手迁。

建议试播顺序：

1. 冻现基轨后只播图，`LocoState=Walk`，Yaw `0/90/180/-90`，确认四向。
2. `LocoState=Run` 同测。
3. 切 `Idle` / `Jump` / `Fall` / `Land` 看 Select。
4. 改 `ClipSpeed` 看走跑速率。
5. 再考虑跟 `getMoveYaw` + `Humanoid.Running` 自动喂参。
