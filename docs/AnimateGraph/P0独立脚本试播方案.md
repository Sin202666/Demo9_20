## 0. 目标与非目标

### 目标

独立 **LocalScript** 旁路试播已发布图 `rbxassetid://90774329769612`：

1. `Animator:LoadAnimation` → `Play`
2. Heartbeat / Stepped 里 `SetParameter` 四参数（名称与图内绿针逐字相同）
3. 先处理与现 Animate 基轨叠播，再验收 Polar 四向、Select 切态、ClipSpeed

### 非目标（本切片禁止顺手做）

- 不改 `Animate/init.client.luau`、`AnimateModule`、`GroundLocomotion`、`StrafeBlend`、`AirLean`
- 不接现 Animate 商业流、不删 `StrafeBlend`、不接技能 Overlay / `AnimationLayer`
- 不新 System、不注册 Utils 键、不新 Remote、不新存档
- **不写** `HRP.CFrame` / `Humanoid.WalkSpeed` / `Store.cframe` / `RootJoint.C0`
- 不把 Spike 上升为正式 loco 写口

## 1. 权威与写口（§1.6 / §1.7）

| 资源 | 权威 / 写口 | 本 Spike |
|------|-------------|----------|
| 位移 / HRP | `CharacterMotion` Compose | **不写** |
| WalkSpeed | `CharacterMoveSpeed` | **不写** |
| ShiftLock 偏航 | Animate `BindToRenderStep("AnimateShiftLockFaceCamera")` | Spike **不写、不 Unbind**。`Enabled=false` **不会**走 `_cleanup`，该写口可能仍在；这是现网写口残留，不是 Spike 新开写口。禁止因此补一套偏航 |
| 空中 lean | Animate `AirLean` Stepped 写 `RootJoint.C0` | 禁用 Animate 后该写口停；Spike **不写** RootJoint |
| 基轨姿态 | 现网 Animate BaseTracks | 试播期停掉，改由图轨表现 |
| 图参数 | 本地玩家 Automatic 下客户端 `SetParameter` | 仅本机表现；P0 不做旁观复制 |
| 经济 / 伤害 / 存档 | 服 | **不碰** |

**§1.6：** 纯动画表现。不以客机姿态/参数结算奖励、伤害、击杀。

**§1.7 必须答清：**

- **谁写位姿/速度：** 仍是 `CharacterMotion` / `CharacterMoveSpeed`。Spike 只 `SetParameter`。
- **谁写腿姿：** 试播期唯一表现源 = 图 `AnimationTrack`。现 Animate 基轨必须停，否则双轨叠姿。
- **互斥：** 见 §3，不用 `ActionArbiter.Override`（其默认 `suppressLoco=true`，会冻位移，超出 Spike 范围）。
- **打断清理：** 角色销毁或 Spike 关闭时 `Stop` 图轨并断开连接。禁用过的 Animate LocalScript **不能**靠再 `Enabled=true` 重跑；实验室用**重生角色**恢复现网 loco。
- **乘骑：** `Character.MountActive==true` 时不播人型图（步态归 SystemMount）；已在播则 Stop 图轨。

## 3. 叠播互斥（必须写进方案）

现 Animate 与图都是 Movement 档，同一 Animator 会叠姿。仅 `stopBaseAction` **不够**：

- `init.client` Heartbeat 仍跑 `GroundLocomotion` / `StrafeBlend`
- Gate 解闸会 `resumeBaseAction` + `resyncAfterBaseUnpause`，基轨又回来
- `AirLean` Stepped 仍写 `RootJoint.C0`，污染图姿态

**选定：停基轨 + 关掉 Animate 脚本。**

启动顺序：

1. `WaitForChild("Humanoid")` → `Animator`；`Animator` 须已在 Workspace 再 `LoadAnimation`
2. `task.wait()` 一帧，降低与 `Animate/init.client` 同帧抢跑
3. **先** `LoadAnimation`（pcall）。失败则 Log 并 **return**，不 Disable Animate
4. 若 `Character:GetAttribute("MountActive")==true`：不 Play、不 Disable，直接 return（或仅挂 Attribute 监听，上马 Stop / 下马再走本流程）
5. 找到 sibling `Animate`（LocalScript）。若能 require `AnimateModule`：`Animate:stopBaseAction()`（**Disable 不会自动 Stop 已有 Track**，也 **不会** 调 `_cleanup` / Unbind 偏航）
6. `animateScript.Enabled = false`（停 Heartbeat / Stepped 连接：loco、Strafe、AirLean、Gate；偏航 RenderStep 可能仍在）
7. `Animator:GetPlayingAnimationTracks()`：停掉不是本图轨、且 `Priority.Value <= Movement` 的残留轨。**不要**停 Action 及以上（技能 Overlay / Land）
8. 再 `Play` 图轨

**不采用：**

- 只 `stopBaseAction`、Animate 继续跑
- `ActionArbiter` `Override` / `suppressLoco`（冻 WalkSpeed）
- 改 `init.client` 接 Spike

**恢复：** Spike `Destroying` / 角色离开时 `graphTrack:Stop`。Animate 已 Disable 的本角色实例不恢复脚本；重生后现网 Animate 重新克隆启动。

## 4. 图驱动契约

AssetId：`rbxassetid://90774329769612`  
加载：`Instance.new("Animation")` + `animator:LoadAnimation`（官方图用法；不走 `AnimationModule` 名轨缓存）

| 参数 | 类型 | 规则 |
|------|------|------|
| `LocoState` | String | 与 Select **针名逐字相同**。合法：`Idle` `StartWalk` `Walk` `StartRun` `Run` `StopRun` `StopWalk` `Jump` `Fall` `Land` `LightLand` `Climb` `Swim` `SwimIdle`。脚本 **不写 `StopWalk`**（现网 `TransitionEnable.StopWalk=false`） |
| `MoveYawRad` | Number | **角度，禁止 `math.rad`。** 0 前、+90 右、±180 后、-90 左。换键 Mag 归零时 hold 上一 yaw |
| `MoveMag` | Number | **恒 `1`**（走跑态不把 Mag 打到 0） |
| `ClipSpeed` | Number | **只这一条**。Walk=`speed/15`、Run=`speed/21`、Climb=`speed/20`，再除 RigScale；其它态 `1` |

`speed` 读 `Humanoid.WalkSpeed`（只读，不写）。RigScale / yaw 用只读 `AnimateMotionHelpers.create`（`getReferenceLookVector` 可先省略，ShiftLock 偏航精度非 P0）。

### 4.1 喂参策略

顶部可强制覆盖，便于 Polar 四向验收：

```lua
local FORCE_LOCO_STATE: string? = nil -- 例 "Walk" / "Run"
local FORCE_YAW_DEG: number? = nil    -- 例 0 / 90 / 180 / -90
```

未强制时自动喂（**简化态，不是完整 GroundLocomotion**）：

- Swimming → `Swim` / `SwimIdle`
- Climbing → `Climb`
- Jumping → `Jump`
- Freefall → `Fall`
- 有移动意图且 `WalkSpeed > 16` → `Run`，否则有意图 → `Walk`
- 否则 `Idle`
- P0 自动路径不写 `Start*` / `Stop*` / `Land` / `LightLand`（可用 FORCE 手测 Select）

循环：`RunService.Stepped`（官方图示例在动画求值前喂参）。

## 6. 验收顺序

1. `SPIKE_ENABLE=true`，进游戏：现基轨停、只见图。`FORCE_LOCO_STATE="Walk"`，Yaw `0/90/180/-90`，确认四向（不要用 1.57/3.14）。
2. `FORCE_LOCO_STATE="Run"` 同测。
3. FORCE 切 `Idle` / `Jump` / `Fall` / `Land` 看 Select（针名报错 = Studio 针不是 `Idle`）。
4. 改 WalkSpeed 或看 `ClipSpeed` 走跑倍率。
5. `FORCE_*=nil` 用 WASD 自动喂参走一遍。
6. 关掉 Spike 或重生，确认现网 Animate 回来（重生）。
