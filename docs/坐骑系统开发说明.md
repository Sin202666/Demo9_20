# 坐骑系统开发说明

统一坐骑/载具域技术参考（拥有 · 生命周期 · 多 Locomotion 驱动 · 规则 · 表现 · 与 3C 契约）。  
业务权威经 **SystemMount**；客户端 Locomotion 经 **MountLocomotion Drivers** 插拔；移速/位移写口须遵守 CMS / CharacterMotion / CharacterControl 分层。  
Control / 相机 / 位移电机细节见 [`CharacterControl模块技术说明.md`](CharacterControl模块技术说明.md)、[`CharacterMotion模块技术说明.md`](CharacterMotion模块技术说明.md)、[`CameraModule模块技术说明.md`](CameraModule模块技术说明.md)。  
架构分层见 [`代码结构和设计开发规范.md`](代码结构和设计开发规范.md)。

## 1. 目标与边界

### 1.1 产品目标

构建**统一坐骑/载具框架**，覆盖多种移动范式，共享拥有、召唤、规则与表现入口，按类型拆分 Locomotion 驱动：

| 类型 | 代表 | 移动范式 | 首期 Driver |
|------|------|----------|-------------|
| **陆地生物坐骑** | 艾尔登法环「托雷特」式灵马 | **双 DriveMode**（见 §5.2.0） | `GroundMountDriver` / `MountRootDriver` |
| **轮式/履带载具** | 汽车、坦克 | 载具物理 / 底盘驱动；油门·刹车·转向 | `WheeledVehicleDriver`（Phase 2） |
| **飞行生物坐骑** | 飞龙 | 三维骑乘（XZ + 升降）；非驾驶舱 | `FlyingCreatureDriver`（Phase 3） |
| **航空器** | 飞机、直升机 | 驾驶舱操控；油门/俯仰/悬停/偏航 | `AircraftDriver`（Phase 4） |

**统一的是：** 拥有、装备、召唤/进入、离开/收回、区域/战斗规则、存档、通信、表现管线入口。  
**分开的是：** 输入映射、位移写口、物理模型、动画集、相机 Profile。

### 1.2 本栈能力（做）

| 能力 | 说明 |
|------|------|
| 服务端权威业务态 | 能否召唤、是否在骑/在载具内、当前 mountId、locomotionType、强制离开 |
| 多 Locomotion Driver | 客户端按 `locomotionType` 实例化对应驱动；Driver 实现统一生命周期接口 |
| 规则与安全 | 禁区、战斗锁、CD、与技能/CharacterMotion 互斥、请求限流 |
| 表现层 | 模型附着、骑乘/载具动画、相机 Profile、基础 VFX/SFX |
| 配置驱动 | `Mount.xlsx` + 分类型扩展字段；CfgFind 只读查询 |

### 1.3 不做（本域外或后期）

| 项 | 说明 |
|----|------|
| 完整养成/图鉴/商城 | 另开迭代；本域只预留 `HasMount` / 发货接口 |
| 双人同骑 / 载客 | 单独立项（同步与挂点成本高） |
| 服务端每帧模拟骑乘物理 | 与现有 3C 冲突；角色网络所有权在客户端 |
| 裸写 WalkSpeed / 旁路 CharacterControl | 见 §6 所有权约定 |
| System 直绑 Remote | 经 Manager + NetWorkManager |
| 用 `IsServer` 分支混写骑乘业务 | 服/客拆模块 |

## 2. 核心原理（与 3C 对齐）

### 2.1 权威模型

```text
┌─────────────────────────────────────────────────────────────┐
│ Server SystemMount                                           │
│  · 拥有/装备/白名单、CD、区域、战斗、与 Drive 冲突           │
│  · 唯一写 MountSession（mounted、mountId、locomotionType…） │
│  · ForceExit / SyncMountState                               │
└──────────────────────────┬──────────────────────────────────┘
                           │ 状态同步（非每帧物理同步）
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ Client SystemMount                                           │
│  · 按 locomotionType 挂载 MountLocomotion Driver             │
│  · 表现：模型、动画、相机、VFX                               │
│  · 输入只发 Request；不定终态                                │
└──────────────────────────┬──────────────────────────────────┘
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
  GroundMount*       WheeledVehicleDriver  FlyingCreatureDriver …
  A HumanoidHost / B MountRoot
         │                 │                 │
         ▼                 ▼                 ▼
   Humanoid+CMS      Vehicle/Chassis     FlightMotor
   或 马根速度          （载具输入层）      （Y 轴+包络）
```

\* `LocomotionType=GroundMount` 再按 `DriveMode` 选 `GroundMountDriver` / `MountRootDriver`。

**一句话：** 坐骑 = **服务端状态机** + **客户端 Locomotion Driver** + **表现**；不是服务端载具模拟器。

### 2.2 与 CMS / CharacterMotion 的关系

| 移动场景 | 写口 | 坐骑域如何使用 |
|----------|------|----------------|
| 日常地面走路/跑步 | **CMS**（`CharacterMoveSpeedBind.pushModifier`） | `GroundMountDriver` 推 `Mount:{mountId}` 的 `mul`/`add` |
| 技能冲刺/击退 | **CharacterMotion** Drive / Impulse | 与 Mounted **互斥**（见 §8） |
| 载具/飞行 | Driver 专用 Motor 或引擎 VehicleSeat | **不走 CMS 日常走路**；进入前 pop 全部 Mount Modifier |
| 输入意图 | **CharacterControl** Intent / LockMask | 地面坐骑沿用；载具/航空器切换输入映射或 `TransferControlOwner` |

角色**平面日常移速**仍遵循 CMS 单写入者；**载具/飞行**使用独立 Driver 写口，但须在本文件 §6 登记，禁止旁路。

```text

        │
        ├─ Client: PlayerInputClientManager     ← SystemInput.Init + Push Gameplay
        ├─ Client: PlayerMountClientManager     ← 订 Mount.Toggle；收 Sync、路由
        └─ Server: PlayerMountManager           ← 薄编排：Remote 路由、PlayerAdded/Removing
                │
                ▼
        SystemMount（服务端）                    ← 拥有、装备、校验、ForceExit、存档
                │ MountNet / NetWorkManager
                ▼
        SystemMount（客户端 SystemModule）       ← Session 镜像、Driver 工厂、表现编排
                │
                ├─ MountLocomotion/
                │     ├─ GroundMountDriver.luau
                │     ├─ WheeledVehicleDriver.luau
                │     ├─ FlyingCreatureDriver.luau
                │     └─ AircraftDriver.luau
                ├─ MountPresentation/            ← 模型、VFX、音效（可选子模块）
```

> 离散快捷键统一经 **SystemInput**（Action / Context / Scheme）；设置页可重绑并写入存档 `InputBindings`。见 [`SystemInput模块技术说明.md`](SystemInput模块技术说明.md)。移动 Intent 仍归 CharacterControl。

| Manager（客） | `StarterPlayerScripts/Manager/PlayerMountClientManager.client.luau` | 订 `Mount.Toggle`、收 Sync、路由 SystemMount |
| 输入路由（客） | `SystemModule/SystemInput` + `PlayerInputClientManager` | Action / Context；坐骑不直连 UIS |

## 4. 统一状态机

### 4.1 会话状态（MountSession）

```text
Idle          未骑乘/未在载具内
Summoning     召唤/进入过渡中（可选，短态）
Active        已激活（骑乘中 / 驾驶中 / 飞行中）
Exiting       离开/收回过渡中（可选）
```

任意态可被 **ForceExit(reason)** 打断 → 经 Exiting 或直接 Idle。

### 4.2 状态迁移（服务端裁定）

| 迁移 | 条件（摘要） | 服务端 |
|------|--------------|--------|
| Idle → Summoning → Active | 拥有、CD、区域、非战斗锁、无 Drive 冲突 | `TryEnter` |
| Active → Exiting → Idle | 主动离开 / CD 开始 | `TryExit` |
| * → Idle | 禁区、战斗、死亡、离服、技能冲突、非法包 | `ForceExit` |

客户端**不得**本地长期维持与 Sync 不一致的 Active。

### 4.3 ForceExit 原因（EnumMgr）

建议枚举：`PlayerRequest` / `ZoneBan` / `CombatLock` / `SkillConflict` / `CharacterMotionDrive` / `Dialogue` / `Cutscene` / `Seated` / `Death` / `Respawn` / `LeaveGame` / `InvalidState` / `AntiCheat`。

## 5. Locomotion Drivers

### 5.1 统一 Driver 接口（契约）

每个 Driver 实现相同生命周期，由 `SystemMount` 客户端按配置实例化：

```lua
-- 概念接口（MountLocomotion-Type.luau）
export type MountLocomotionDriver = {
	locomotionType: string,
	mountId: string,

	-- 进入激活：装配模型、占输入/相机、注册写口
	enter: (self: MountLocomotionDriver, ctx: MountEnterContext) -> boolean,
	-- 每帧/Heartbeat 更新（可选）
	update: (self: MountLocomotionDriver, dt: number) -> (),
	-- 离开：拆约束、pop Modifier、还原相机/控制
	exit: (self: MountLocomotionDriver, reason: string) -> (),
	destroy: (self: MountLocomotionDriver) -> (),

	-- 查询（供规则层）
	isActive: (self: MountLocomotionDriver) -> boolean,
	getFlatSpeed: (self: MountLocomotionDriver) -> number?,  -- 供服端观测/包络
}
```

### 5.2 GroundMount（陆地生物 · 双 DriveMode）

#### 5.2.0 DriveMode：A 保留 / B 开启

| DriveMode | Driver | 物理根 | 适用 | 配置 |
|-----------|--------|--------|------|------|
| **HumanoidHost（A）** | `GroundMountDriver` | 玩家 Humanoid | 轻度项目、快速接入 | 默认；`ExtJson.DriveMode` 省略或 `"HumanoidHost"` |
| **MountRoot（B）** | `MountRootDriver` | 马物理根 `MountPhysicsRoot` | 托雷特主从（人上鞍） | `"DriveMode":"MountRoot"` |

```text
A HumanoidHost：输入 → Humanoid:Move → 人胶囊  │ Weld → 马模型（挂件）
B MountRoot：   输入 → 马根速度/偏航 → 马碰撞体 │ Weld → 人（PlatformStand 上鞍）
```

- **A 继续维护**：CMS Modifier、HipHeight、马焊人；轻量体验够用。  
	- B 开发中（v1 已可玩）：不走 CMS 日常走路；`cruiseSpeed = 16 × SpeedMul`；`MountPresentation.attachRoot`；Animate 仍看 `MountActive`。  
	- B 已补：提交式地面 180、二段跳 Redirect/Flip 改向（写马物理根，非 Humanoid）。  
	- **样例**：`6001001` 独角兽当前为 **MountRoot**；改回 A 只需 `DriveMode=HumanoidHost`。

B 后续：见 **附录 D.9**。D.9 P0 已落地；**P1 控制核**（Walk/Gallop 蓄力、两段减速、射线贴地、二段跳短 CD）已落地。下一档：相机 Profile / Sit / 蹄地毫米微调。

#### GroundMountDriver（A · HumanoidHost）

**适用：** 马焊人、Humanoid 地面移动（轻度）。

| 项 | 方案 |
|----|------|
| 位移 | Humanoid 地面移动；**不**用 VehicleSeat 作核心 |
| 加速 | CMS `pushModifier("Mount:"..mountId, { mul, accelDuration, decelDuration })` |
| 模型 | 附着角色（Weld/Motor6D/挂点）；Phase 手感期可用 Part 占位 |
| 动画 | ActionArbiter 压制人腿 loco；播坐骑 gait（idle/run/jump）——可后置 |
| 跳跃 | JumpHeight 提升；空中 Freefall 二段跳一次（`CanDoubleJump`） |
| 相机 | CameraMode `PushMode` 骑乘 Profile（可后置） |
| 手感 | 转向：关 AutoRotate + 按速度钳制偏航角速度；加减速时长经 CMS Modifier 覆盖 |

**托雷特式体验要点：** 召唤/灵体消失表现、比步行明显更快、可跳、室内/战斗强制离开、骑乘动画独立于步行。

**托雷特转向逻辑（GroundMountDriver）：**

```text
输入（相机相对 MoveDirection）
        │
        ├─ DesiredHeading：输入方向作为期望朝向
        ├─ Yaw：有限角速度转向 DesiredHeading（低速快 / 高速慢）
        └─ Move：仅沿当前马头 forward * throttle（禁止 strafing 侧滑）
```

急转表现为大半径弧线，而不是「人型侧滑 + 身体慢转」。二段跳：离地 ≥0.12s 后空中再按 Space/A，给一次上升冲量。

#### 5.2.1 产品决策：做满托雷特（优先于扩类型）

**已拍板：** GroundMount 以艾尔登法环「托雷特」为手感标杆，**在进入 Phase 2 车辆之前，先做满灵马控制核**。  
模型 / 动画 / 召唤 VFX **可继续占位**；本决策重心是控制与手感，不是换皮。

**一句话公式（验收口径）：**

```text
托雷特手感 ≈
  DesiredHeading(相机输入)
  + YawRate(speed) 追朝向
  + Velocity ≈ Forward(yaw) × Speed(gait, throttle, accel/decel)
  + AirJump 一次
  − Strafe（禁止人型侧滑）
```

**已落地（手感雏形）：** 朝向耦合 `Move(forward*throttle)`、速度相关 yawRate、CMS 加减速时长覆盖、二段跳冲量、Part 占位、M 键闭环。

**待做满（按优先级，仍属 GroundMount / 不开新 LocomotionType）：**

| 优先级 | 项 | 说明 | 验收要点 |
|--------|----|------|----------|
| P0 | 弯中掉推力 | `throttleEff = throttle × turnAlignFactor`（`TurnAlignMin`/`TurnAlignPow`） | 急转不再满速贴地漂移 ✅ |
| P0 | 地面急回头 | **提交式 180**：一帧反向即锁目标偏航，松杆也拧完；`AboutFaceTurnMul`/`Brake`/`CooldownSec` | 点一下 S 也能掉头 ✅ |
| P0 | 瞬 180 | 跳→反向→二段跳：翻转窗**限速**追朝向（禁一帧硬切 CFrame） | 空中可掉头且不瞬切 ✅ |
| P0 | 转向曲线分段 | `TurnSpeedPow`；常态空中 `AirTurnMul` | 低速灵、疾驰钝 ✅ 雏形 |
| P0 | **弯中巡航不掉速** | 缓弯（~35°内）不脉冲；`TurnCruiseDot` 或 Move/转向解耦 | W+左右转均速稳定；见 D.8 |
| P0 | **跳跃前冲 / 空中保速** | D.4.2 包络 | ✅ |
| P1 | 步态档 | Idle → Walk → Gallop | 满油需攒一会儿才到顶速 ✅ |
| P1 | 两段减速 | 松杆先滑后刹（τ_slip ≠ τ_brake） | 停步更沉 ✅ |
| P1 | 空中规则（其余） | 二段跳短 CD；落地顿挫（可选） | 落地不人型瞬加速 ✅ |
| P2 | 相机 Profile | 疾驰略拉远；PushMode/PopMode | 速度感加强（非控制核必需） |
| P2 | 动画 / 倾身 | ActionArbiter 压人腿；马 gait + 急转侧倾 | 表现放大层；Part 阶段可跳过 |
| P2 | 召唤/收回表现 | 灵体出现/消失 VFX | 托雷特仪式感；可后置 |
| P2 | 规则打磨 | 禁区/战斗 ForceExit、失败 Tip | 商业 P0 规则，与手感并行亦可 |

**不做进「做满托雷特」范围（另阶段）：** 双人同骑、飞行、载具物理、商城/图鉴养成。

**与扩类型的关系：** Phase 2（车）/ 3（龙）/ 4（航空器）**排在托雷特控制核达标之后**；Driver 插拔架构不变，灵马线不因扩类型停更。

### 5.3 WheeledVehicleDriver（Phase 2）

**适用：** 汽车、坦克等。

| 项 | 方案 |
|----|------|
| 位移 | VehicleSeat **或** 自研 Chassis（LinearVelocity/约束）；**不走 CMS 日常走路** |
| 输入 | 油门/刹车/转向轴；经专用输入层或 `TransferControlOwner` |
| 角色 | Seated / 焊接到载具；Humanoid 不参与 loco |
| 相机 | 复用 VehicleCamera 思路（项目已有 VehicleCamera 模块） |
| 与 3C | 进入载具时 Pop CMS Mount Modifier；退出时还原 CharacterControl |

### 5.4 FlyingCreatureDriver（Phase 3）

**适用：** 飞龙等「骑乘飞行」。

| 项 | 方案 |
|----|------|
| 位移 | 专用 `FlightMotor`（或 CharacterMotion 扩展 Recipe，须评估与 Drive 互斥） |
| 输入 | 前进 + 上升/下降；非驾驶舱六自由度 |
| 约束 | 最大高度、禁飞区、最低高度强制降落 |
| 安全 | 服务端高度/速度包络（观测为主；硬钳谨慎） |
| 动画 | 翅膀/悬停/俯冲动画集 |

### 5.5 AircraftDriver（Phase 4）

**适用：** 飞机、直升机。

| 项 | 方案 |
|----|------|
| 控制 | `controlScheme`: Plane / Helicopter；与 FlyingCreature **分 Driver** |
| 飞机 | 速度向量、俯仰、简化失速/最低高度 |
| 直升机 | 悬停、垂直升降、偏航 |
| 位移 | 载具 Assembly 驱动；角色 Seated |
| 相机 | 驾驶舱 / 第三人称可配置 |

## 6. 所有权约定（强制）

| 资源 / 决策 | 允许写入 / 权威方 |
|-------------|-------------------|
| MountSession（是否在骑、mountId、type） | **仅** SystemMount（服） |
| 能否 Enter / Exit | **仅** SystemMount（服）校验 |
| 拥有列表 / 当前装备 | **仅** SystemMount（服）+ SystemSave |
| WalkSpeed / ExpectedWalkSpeed | **仅** CMS（GroundMount 经 Bind Modifier） |
| 载具/飞行速度 | 对应 Driver 登记之写口；**禁止**与 CMS 双写同一相位 |
| Humanoid 日常 MoveDirection | 引擎 + CharacterControl Intent |
| 技能 Drive / Impulse | **仅** CharacterMotion |
| Jumping 禁跳 / Move 锁 | CharacterControl PushLock |
| 骑乘 loco 动画占闸 | ActionArbiter Acquire |
| 相机 Mode / Profile | CameraModule PushMode / PopMode |
| ControlModule Disable | **仅** PlayerControlsBridge（Transfer 时） |

**GroundMount 禁止：** 裸写 `Humanoid.WalkSpeed`、用 VehicleSeat 冒充马匹核心驱动。  
**Vehicle/Aircraft 禁止：** 进入后仍保留 `Mount` CMS Modifier 导致双加速。

#### D.4.1 托雷特「跳跃前冲」调研整理（2026-08-27）

> 来源：Wiki / 社区手感文（非 From 反编译）。用于验收口径与实现映射，不声称精确帧数据。

**产品语义（一句话）：**  
托雷特的跳 = **带着地面水平动量的长弧** + **空中仍可沿马头给一点推进**；二段跳再叠「加高 + 加远 + 可改向」。  
对比人型：不是「原地竖直上跳再落地」；对比车：不是空中完全无控。

| 层级 | 托雷特行为（标杆） | 设计意图 |
|------|-------------------|----------|
| **首跳** | 跳得比步行**更远**；疾驰中起跳保留（并延续）前进感 | 探索跨沟、战斗跃过扫击 |
| **空中持续** | 空中仍有一定前向控制（非纯弹道）；转向弱于地面 | 「马」而非「挂在空中的人」 |
| **二段跳** | 再给升力 + **加长跳距**；可在此刻**改写朝向/水平动量** | 最快掉头手段；绕开地形/AoE |
| **落地** | 落地后立刻能再疾驰（顿挫可选、要轻） | 保持骑乘流畅，不人型卡顿 |

**与「瞬 180」的关系（勿混）：**

```text
地面急回头     = 对向杆 → 掉推 + 提交式 yaw（已做）
空中瞬 180     = 跳 → 反向杆 → 二段跳限速追转（已做）
跳跃前冲（本项）= 首跳/滞空水平位移要「远」；与瞬 180 正交，可并存
```

**公开资料要点摘录：**

1. *「Torrent's jumps go further than yours」*（Wiki）→ 验收看**水平距离**，不只 JumpHeight。  
2. *二段跳 completely redirecting momentum midair, enhancing length and height*（Parry Everything）→ 二段跳 = 改向 + 加远 + 加高。  
3. *change direction as you double-jump = quickest turn while running*（Wiki）→ 已用翻转窗实现；前冲项不要削弱它。  
4. 地面有轻微加减速/转向惯性，但摩擦故意压低；二段跳用来绕过「马感」限制（同文）。

**验收手测：**

- 疾驰空格：落点应明显在起跳点**前方**（比同 JumpHeight 人型更远）。  
- 静止/慢走空格：仍有一小段前跃，不是纯竖直上跳。  
- 空中按住 W：弧线继续前伸，不是「跳起来就飘停」。

#### D.4.2 跳跃前冲手感方案（贴托雷特）

> 2026-08-27 初稿；**同日复核修订**（合理性 / 贴合度）。

##### 复核结论（先看这）

| 判断 | 项 | 说明 |
|------|----|------|
| ✅ 成立 | 「太干」诊断 | 一帧改 flat / 疾驰再 +boost / 二段跳一帧改向量 → 像踢一脚，不像跃弧 |
| ✅ 高贴合 | 疾驰跳以**继承动量**为主 | 托雷特是「带着跑跳出去」，不是起跳再弹射加速 |
| ✅ 高贴合 | 二段跳 = 第二拍跃起 + 可改向 | 与 Wiki / 手感文一致；且须兼容已做的限速瞬 180 |
| ✅ 成立 | 禁止喷气常推、禁硬切 CFrame | 喷气→jetpack；硬切→已否决 |
| ⚠️ 过冲 | **上升段强 LeapPush 当加远主因** | 托雷特更偏**弹道继承 + 滞空 + 二段再跃**；持续前推只宜作短时润色，不宜当主引擎 |
| ⚠️ 脆 | **用 `vy>0` 门闩推包络** | 过顶会突然断推、曲线易打折；应改为**事件起算的时间包络** |
| ⚠️ 过正 | **二段跳水平完全禁止瞬时分量** | 玩家体感「再跳那一下」有方向承诺；纯慢拧会糊，伤瞬 180；应为**部分即时混合 + 窗内收尾** |
| ⚠️ 风险 | 参数过多 + 多写口叠力 | Push + 硬/软 Maintain + `Move` 空中油门易抢权威、难调 |

**一句话修订：**  
方案骨架保留（去干踢、继承动量、二段再跃、渐变改向），但把「加远」从「上升强推」改回 **「保动量的长弹道 + 短时润色包络」**；二段跳水平用 **混合改向**，不是零瞬态。

##### 为什么现在干（仍成立）

| 现状写法 | 体感问题 |
|----------|----------|
| `_applyFirstJumpBoost` 一帧改写 flat | 起跳「啪」一下，无拉伸 |
| 疾驰仍 `+ FirstJumpHorizBoost` | 满速再踢，假且冲 |
| `_tryDoubleJump` 一帧 `old*keep+aim*boost` | 水平向量突变，火箭改轨感 |
| `AirSpeedMaintain` 每帧硬 `max` | 速度被钉住，少曲线 |

##### 贴合度：托雷特实际更像什么

公开资料能确认的只有手感层（非帧数据）：

1. 跳得比步行**更远** → 验收看水平距离，但实现上优先 **不掉水平速 + 略滞空**，不是必须猛加水平冲量。  
2. 二段跳 **加高 + 加远 + 可改向** → 第二拍清晰；改向发生在二段跳时刻附近。  
3. 控制刻意**低摩擦、偏流畅**（马感只保留一点），双跳用来绕过马的转向钝。  
4. 坠崖未先跳则可能没二段跳 → 二段跳挂在「主动跃起」状态机上（你们已有离地延迟，保持即可）。

**推断（中置信）：** 托雷特空中不是喷气摩托；主感是 **弹道 + 动量保留 + 二次起跳改轨**。  
因此：D.4.2 初稿把「上升持续前推」抬成加远主因，**贴合度中等偏高估**——作为润色可以，作为主引擎容易滑向 jetpack。

##### 修订后目标模型

```text

跳跃前冲 ≠ 上升段强喷气
跳跃前冲 = 继承地面动量（疾驰几乎只继承）
            + 短时时间包络润色（可选、疾驰弱）
            + 滞空软保速（补 Humanoid 空中掉速）
二段跳   = 第二拍升力（可短促）
            + 水平：部分即时转向 aim + 窗内收尾（非 0%、非 100% 一帧定稿）
            + 同款短时润色包络（第二拍加远）
```

### D.8 弯中速度波动：根因分析 & 托雷特对比（2026-08-27 · 新会话优先）

> **现象**：向前走 + 左右转弯（非 180）时，奔跑速度**时快时慢**、有脉冲感。  
> **已排除**：提交式 180 误触（`AboutFaceDot` 已从 -0.15 收紧至 -0.65）；修复后现象仍在。

#### D.8.1 本栈实际链路（为何 WalkSpeed 满速仍会变慢）

```text
ControlModule 意图 (intent, throttle)
        │
        ▼
GroundMountDriver.update
  ├─ yaw：限速追 intent（TurnRateDeg × speed 分段）
  ├─ turnAlignFactor = f(look·intent)   ← 弯中掉推力
  └─ Humanoid:Move(look × throttle × turnAlignFactor)   ← 幅度随夹角变
        │
        ├─ CMS：MoveDirection.Magnitude > 0.01 → WalkSpeed 目标 = 合成满速（二元，不看幅度）
        └─ Humanoid  locomotion：Move **向量幅度**影响实际推力 → 真实速度仍随 turnAlignFactor 波动
```

**关键结论：** CMS 显示/目标可以是满速，但 **`Move` 幅度被 `turnAlignFactor` 砍掉** 时，Humanoid 实际推进力下降 → 体感「时快时慢」。  
这不是 CMS `AccelSec/DecelSec` 的直接锅（除非 Move 幅度跌到 `<0.01` 触发无输入减速，当前配置下极少）。

#### D.8.2 当前 `turnAlignFactor` 为何在「普通转弯」也持续打折

配置：`TurnAlignMin=0.1`，`TurnAlignPow=1.25`，公式：

```text
t = clamp(look·intent, 0, 1) ^ TurnAlignPow
turnAlignFactor = TurnAlignMin + (1 - TurnAlignMin) × t
```

| look·intent（夹角） | turnAlignFactor | 体感 |
|---------------------|-----------------|------|
| 1.0（0°） | 1.00 | 满速 |
| 0.87（~30°） | ~0.84 | 明显掉 |
| 0.71（~45°） | ~0.73 | W+A 常见 |
| 0.50（60°） | ~0.49 | 接近半速 |
| 0.0（90°+） | 0.10 | 地板 |

**脉冲来源（动态）：**

1. **W → W+A**：意图偏转 → 夹角变大 → factor 掉 → 慢；马头追上 → factor 回 → 快。  
2. **相机相对输入**：马在转、相机也在动 → `intent` 相对 `look` 连续变化 → factor 每帧抖。  
3. **限速 yaw 稳态**：高速时 turnMul 低，look **长期追不上** intent → factor **长期 <1**（尤其画弧/8 字）。  
4. **与 180 无关**：`AboutFaceDot=-0.65` 仅 ~130°+ 才提交；30°～60° 弯走的是 turnAlign 地板，不是 AboutFace。

#### D.8.3 托雷特（公开语义）vs 当前实现

| 维度 | 托雷特标杆（推断 + 社区/Wiki） | 当前 GroundMountDriver |
|------|-------------------------------|------------------------|
| 设计优先级 | **低摩擦、流畅**；马感只留一点 | 弯中掉推力 **每帧** 乘在 Move 幅度上 |
| 前进 + 缓弯 | scalar 速度大致保持；方向渐改 | look·intent 30° 即 ~16% 掉推力 |
| 前进 + 急弯 | 掉速 + 大半径弧（涌现） | 同左，且 factor 可低至 0.1 |
| 180 / 对向 | 提交式掉头、掉速再加速 | 提交式 180 + Brake（已收紧触发） |
| 速度实现猜测 | 引擎内**标量速度 + 朝向**解耦；非「每帧砍 Move 幅度」 | `Move(方向×turnAlignFactor)` 耦合过紧 |
| 跳跃 | 弹道继承 + 二段再跃（D.4.2 已对齐） | ✅ 已修订 |
| 空中 | 弱转向 + 保动量 | ✅ AirSpeedMaintainSoft 等 |

**贴合度判断：**

- **急转掉速**：方向对，但 **阈值/曲线过 aggressive**——托雷特不会在 ~30° 缓弯就砍 16%+ 推力。  
- **时快时慢脉冲**：**不符合**托雷特「minimize friction」——属于实现副作用，不是目标手感。  
- **弯中掉推力** 应近似 **涌现**（速度×曲率×夹角），而非 **每帧 look·intent 线性乘子**。

#### D.8.4 推荐改法（下一编码回合 · 按优先级）

**P0 — 巡航弧死区（最小 diff，优先试）**

```text
若 look·intent >= TurnCruiseDot（建议 0.82～0.86，约 ≤35°）：turnAlignFactor = 1
否则沿用现有 pow 曲线，但 TurnAlignMin 提高到 0.55～0.7（勿再用 0.1）
```

ExtJson 候选：`TurnCruiseDot=0.85`，`TurnAlignMin=0.65`，`TurnAlignPow=1.1`

**P0 — Move 幅度与转向解耦（更贴托雷特）**

```text
Move 方向 = look（或 slerp(look,intent,小系数)）
Move 幅度 = throttle（满杆即满幅度，不再 × turnAlignFactor）
转向惩罚改到：
  - 方案 A：仅当 alignDot < TurnCruiseDot 时 scale CMS mul 或水平速度 cap
  - 方案 B：velocity 朝 look 软对齐（每帧 lerp 水平速度方向），scalar 速度保持
```

**P1 — 涌现式弯中掉速**

```text
turnAlignFactor = lerp(1, curve(alignDot), (speed01 ^ p) × turnSeverity)
turnSeverity = 仅当 alignDot < 0.5 时升到 1
```

**勿做：** 继续降低 `TurnAlignMin`；用 CMS 二元无输入触发减速代替（会更抖）。
