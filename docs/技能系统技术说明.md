# 技能系统技术说明

客户端/服务端技能运行时技术参考（编排 · 状态机 · 命中 · 同步 · 与 3C 契约）。  
业务槽位与默认装备经 **SystemSkill**；施法经 **GroupSkill**；单段时间轴与命中经 **BaseSkill**。  
技能内容作者请同时阅读 [`技能模块作者规范.md`](技能模块作者规范.md)（配置约定与禁旁路）。  
Control / 相机细节见 [`CharacterControl模块技术说明.md`](CharacterControl模块技术说明.md)、[`CameraModule模块技术说明.md`](CameraModule模块技术说明.md)。  
Last Modified: 2026-09-01（SkillHitPresentation 服写口拆层）

## 1. 目标与边界

| 能力 | 说明 |
|------|------|
| 槽位装备 | 服务端权威 Equip/Unequip；默认冲刺/主动技由 GameConfig 注入 |
| 组技能编排 | CD、跨槽打断、派生链、`skillCastId` 生命周期 |
| 基技状态机 | States / Transitions / Phase1 / ControlOpen；时间轴 SkillAction |
| 命中结算 | 服务端 Hitbox → HitResolver → DamageResolver；逻辑怪经纯数据 OBB；`combatSeed` 服端生成 |
| 表现同步 | SkillSyncDispatcher + Router（半径 / 画质过滤 / cast 订阅） |
| 表现预测 | 可选 soft-merge；旁观不预测 |
| 与 3C 契约 | 位移=`CharacterMotion` 电机（Drive 经 `DashStyleRoll`；击退=`ApplyKnockback` Impulse）；禁跳/禁奔=`CharacterControl.PushLock`；冻腿=`SkillActionLock`→ActionArbiter；锁速=`LockMovement`→CMS |

**不做：**

- 业务直绑 Remote（经 Manager + SkillNet）
- 客户端权威 Hitbox / 客户端本地派生
- 裸写 `Humanoid.WalkSpeed` / 直调 `GetControls():Disable` / 旁路 FOV
- 服务端位移包络对账（**轻量**：能力窗观测；击退可钳回；非全权威模拟）
- 完整运营级 Buff 系统（当前 `SkillBuffUtil` 为最小窗）
- 用 `LocalMonster` / 隐形 Part 做逻辑怪权威伤害体积（已否决；见 §9.1）

**相关但不并入本栈：**

| 模块 | 关系 |
|------|------|
| CharacterControl | 禁跳 / 禁奔跑 / Move 锁 / Transfer；技能只 `PushLock`/`PopLock` |
| CharacterMoveSpeed（CMS） | 唯一写 WalkSpeed；`LockMovement` 推 Modifier |
| ActionArbiter | 冻 loco / facing / cameraOwner；经 SkillActionLock 聚合 |
| CameraModule / CameraImpulse | 冲刺 FOV 脉冲；勿直写 FieldOfView |
| SystemSave / 战斗系统 | CD 时间戳、伤害扣血、Buff 门控 |
| SystemEnemy / EnemySim | 逻辑怪创建·Hit 门面；AI/位移/**击退/浮空**/M2 路点批处理进 `CombatWorld.Phase.EnemySim`（**怪移动不是技能时钟**；技能只经 Hit 桥接；Sync **20Hz**） |

## 2. 分层架构

```text
输入 / UI / 装备
        │
        ├─ Client: PlayerSkillClientManager  ← SystemInput Action、CombatWorld.Init、Remote 转发、SYN_PLAYER_CFRAME→CharacterMotion
        └─ Server: PlayerSkillManager         ← SystemPlayerSkill.Init、Release/Stop/PLAYER_AIM_SAMPLE Remote 转发
                │
                ▼
        SystemPlayerSkill（服 System / 客 SystemModule）  ← 槽表、跨槽/门控、旁观工厂、Syn 路由
        SystemSkill（服务端）                             ← 槽位装备权威、默认技能、门控
                │ BindGroupSkill
                ▼
        GroupSkillClient（ClientSideCode）                ← 预测、旁观
        GroupSkillServer（ServerStorage SystemSkillRuntime）← CD、打断、派生、cast 生命周期
                │
                ├─ GroupSkill*InstanceRuntime ← 单次施法运行器（服 Runtime 与 GroupSkillServer 同目录）
                └─ BaseSkillClient / Server   ← 状态机 + SkillAction 时间轴（Server 在 SystemSkillRuntime）
                        │
                        ├─ SkillAction/*      ← Animation / LockMovement / DashStyleRoll / LookAt
                        ├─ CombatWorld        ← 同侧唯一战斗仿真 Heartbeat（Cooldown/EnemySim/SkillRuntime/Hitbox/StatusEffect）
                        ├─ Hitbox（检测）+ HitResolver（服 System 写口；客 ToolSystem stub）
                        └─ SkillSyncDispatcher → SkillSyncRouter → SkillNet

配置：GameConfig.技能系统 + Skill.xlsx / CfgFind
通信：Utils.SkillNet（勿直依赖 Msg 下 Remote）
校验：SkillModuleValidator + SkillDataSchema + SkillStateMachine
作者规范：docs/技能模块作者规范.md
逻辑怪总方案：docs/战斗仿真ECS迁移方案.md §4.3.2 / §4.5
```

## 4. 施法全链路

```text
[输入] SystemInput → PlayerSkillClientManager → SystemPlayerSkill.OnSlotPressed
   → GroupSkillClient.onInputBegan
       ├─ 派生：FireServer(derive) —— 禁止本地派生（P0）
       └─ 新释：clientPredictCastId → FireServer + 可选表现预测

[服：可否释放] PlayerSkillManager → SystemPlayerSkill.OnRelease → GroupSkillServer.requestRelease
   → CD 权威
   → SkillReleaseCrossCheck.runAll
   → 采纳/生成 skillCastId、combatSeed
   → sanitizePlayerCastInput（releaseCF=角色 Pivot；targetCF 距离钳制）
   → GroupSkillInstanceRuntime.start → BaseSkillServer tick

[时间轴]
   Client：BaseSkillClient + SkillAction（可预测 hold → soft-merge）
   Server：BaseSkillServer；serverMode 下 SkillAction 裁剪（如仅 Animation）
   Phase1 / ChainOpen / Released：SkillControlRuntime
   帧循环：服 `UpdateManager` / 客 `PlayerSkillClientManager` 调 `CombatWorld.Init`；Runtime/弹道/Hitbox 窗经 `CombatWorld.register`

[命中]
   Server：Hitbox.check → HitResolver.applyHit → DamageResolver
   逻辑怪：check 末尾 `collectLogicalOverlapHits` → 结果键为 number id → `applyLogicalEnemyHit` → `SystemEnemy.Hit`
   弹道：ProjectileLinearRuntime（Phase.Hitbox）推进 Hitbox；`onProjectileHitServer` / 障碍射线 → ImpactResolver（同认 id）
   Client：CLIENT_HITBOX_DISABLED=true；LocalMonster CanQuery=false（不得权威扫逻辑怪）

[同步]
   SkillSyncDispatcher → SkillSyncRouter（半径 + 低画质/炼药过滤）
   → SynSkillEffect / FixSkillTime / StopSkill 等
   中途事件（ProjectilePath/HitConfirmed 等）：SystemPlayerSkill（客）按 castId 路由 → BaseSkillClient.handleServerEvent → skillModule.onServerEvent

[收尾]
   终态 → Stop / destroy；CD 与表现可并行
   跨槽打断：停 Action/放权；状态机可不强制结束；禁派生（见 §7）
   死亡：interruptAllRunningCasts
```

## 5. Client / Server 职责对照

| 维度 | BaseSkillClient | BaseSkillServer |
|------|-----------------|-----------------|
| 定位 | 表现 façade + 时间轴对齐 | 逻辑 / 命中 façade + 同步广播 |
| Hitbox | 默认关闭 | RuntimeHost 权威检测 |
| SkillAction | 完整表现 Action | `serverMode=true`（裁剪） |
| 预测 | `predictPresentation`：hold + soft-merge | 无表现预测 |
| 派生 | 只响应服端 Derived 事件 | 条件求值 + 转段权威 |

**GroupSkill：**

| | Client | Server |
|--|--------|--------|
| CD 预检 | 本地 UX；最终以服为准 | 存档/内存权威 |
| 打断 | `interruptAllCastingForCrossSlot` | `interruptCrossSlotCast` |
| 预测 | 一期预测 + 拒释清理 | 确认 castId / 拒释回包 |

## 6. 与 3C 契约

停腿两通道勿混用（详见 CharacterControl 文档 §5）：

| 诉求 | 用谁 |
|------|------|
| 冻移速 / 禁跳·冲刺·交互 | `CharacterControl:PushLock` / `Transfer` |
| 冻 loco 动画 / 抢朝向 | `SkillActionLock` → ActionArbiter |
| 短时锁速（可不关 Controls） | `LockMovement` → CMS，或 `PushLock({ Move=true })` |
| 前冲 FOV | `CameraImpulse.emit` |

**位移 Gate 模板（强制）：** `DashStyleRoll` = SkillActionLock + ActionArbiter + `CharacterMotion` Drive + CameraImpulse。  
禁止：裸 BodyVelocity 翻滚/角色击退、直写 WalkSpeed / AssemblyLinearVelocity 做能力位移、旁路 FOV、直调 ControlModule。
命名消歧：Locomotion Sprint（按住奔跑）≠ 技能冲刺 NewRoll（Q）。

## 7. 冷却 · 打断 · 派生

| 能力 | 要点 |
|------|------|
| 冷却 | 玩家存档时间戳；可叠 CDR/Haste；与表现并行 |
| 跨槽打断 | 仅当打断方 `InterruptionPriority` **严格大于** 被打断方；默认档 50；NewRoll 参考 70 |
| 打断动作 | 立即 Over SkillAction / 放权；**不**强制 Stop BaseSkill 状态机 |
| 打断后禁派生 | `ENABLE_DERIVE_SUPPRESS_AFTER_CROSS_INTERRUPT=true`（双端同值）；本施法不可再接段；runtime 清空后复位。语义表见作者规范 §2.3 |
| 互斥 | 同槽 Phase1 Locked；`SkillActionExclusive` / TrackOwner 管并行轨与同名动画 |
| 派生 | `Skill[]` + 声明式/`function` condition；Phase1 未完成走派生；仅服端落地 |

## 8. 表现预测与 soft-merge

- 总闸：`SkillDataSchema` 内 `GLOBAL_PREDICT_PRESENTATION_ENABLED`
- 单技：`Data.predictPresentation == true` 且总闸开才预测
- 流程：本地无 Hitbox 推至 ControlOpen / Phase1 后 **hold** → 服确认同 castId → **soft-merge**（时间/状态/物理/动画/闸 adopt）
- 禁止：预测二次起冲、FOV 二次放大、清 `_actionLockHeld` 却不 Off
- 拒释：须清预测物理与闸（见 NewRoll 组模块头验收清单）
- 旁观：不预测，等 `BaseSkillStarted`

## 9. 命中与同步

**命中**

- 配置：`hitboxConfig` + `DamageProfiles`（及弹道 `ProjectileProfiles`）须完整，即使客户端 Hitbox 关闭
- 输入钳制：`sanitizePlayerCastInput`（作者勿信客户端落点）
- Buff：`SkillBuffUtil`；门控依赖 `GameConfig.战斗系统.启用`
- 物理假人/角色：仍走 `GetPartsInPart` + 碰撞组过滤（`Enemy`/`Player`/`Summon`/`Broken`）
- 逻辑怪：见 §9.1（权威 OBB **不依赖**碰撞组；客表现层 **须** `CollisionGroup="Enemy"` 且 `CanQuery=false`）

**同步（SkillSync）**

- Dispatcher：统一 `dispatch`；按 SyncPolicy 选半径 / track
- Router：半径玩家 + `skillCastId` 订阅者保证 Stop 可达；低画质/炼药可过滤他人 FX；TTL + PlayerRemoving 清理
- 事件面经 SkillNet：`SynSkillEffect`、`FixSkillTime`、`StopSkill`、`DamageTip` 等

### 9.1 逻辑怪桥接（服纯数据 OBB）

总方案：[`战斗仿真ECS迁移方案.md`](战斗仿真ECS迁移方案.md) §4.3.2（L0–L5 + I7=A）+ §4.5（C0a/C0b / Displace / Airborne）。

> ~~Sync 10Hz~~ **已过时** → 现行 **20Hz**。  
> ~~客无 CollisionGroup~~ **已过时** → 现行 `CollisionGroup="Enemy"`（仍 `CanQuery=false`）。

```text
CreateLogicalEnemy → EnemyLogicalStore（cframe + bboxSize + hp）
        │ EnemySim.add
        ▼
CombatWorld.Phase.EnemySim=15
  · LogicalAirborne.step（优先；浮空禁贴地）
  · LogicalDisplace.step（地面击退）
  · RangerAi.step → LogicEntityMotion.integrate（贴地+挡墙；air/move 锁则跳过）
  · Sync TRANSFORM 20Hz
        │
服 Hitbox / 弹道（Player|Mirror）
  · GetPartsInPart（物理体）
  · collectLogicalOverlapHits（纯数据 OBB）→ { [id]=Position }
        ▼
HitResolver.applyLogicalEnemyHit
  · _attachLogicalHitPresentation → SystemEnemy.Hit + LogicalHitValidate
  · 扣 Store.hp；SkillHitPresentation + NPCCosmeticHit
  · Airborne.tryApplyFromHitbox 优先，否则 Displace
  · ≤0 → DespawnById → ENEMY_LOGICAL_DEATH → 客 LocalMonster Destroy
```

| 约定 | 要求 |
|------|------|
| 权威体积 | `Store.cframe` + `bboxSize`；**禁** LocalMonster / 隐形 Part 当伤害体积 |
| 客表现 | `SystemLogicalEnemy`：`CanQuery=false`、`CanCollide=false`、**`CollisionGroup="Enemy"`**；PivotTo / 动作 |
| 校验 | `LogicalHitValidate`：alive / combatReady / 白名单空=全开 / 距离 |
| 门控 | `GameConfig.战斗系统.启用`；`GetData.GetDmg` |
| 调度 | AI/位移/击退/浮空只进 `EnemySim`；**禁**每怪 `Heartbeat` |
| 碰撞组 | 打逻辑怪**不依赖**碰撞组做权威；表现层须 `Enemy` 组；贴地射线用 `RayCast` 预设 `Ground`（`workspace.场景`） |
| 受击运动 | `PhysicsEffectName` → AirborneProfile 或 DisplaceProfile；陨石现行为地面击退档 |
| 未做 | Ranger Attacking；`enemyConf` bbox / airWeight 表列；客 `air_*` Anim（回退 idle）；SkillBuff 堆叠/DoT |

## 11. 配置（GameConfig.技能系统）

| 键 | 含义 |
|----|------|
| `启用` | false：不跑 SystemSkill.Init / 双 Manager |
