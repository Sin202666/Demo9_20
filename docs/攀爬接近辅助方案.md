# 攀爬接近辅助方案（ClimbAssist）

> **定位**：接近辅助，**不是**替换引擎攀爬检测。  
> Author: 林奥宇 · Created: 2026-08-17 · Last Modified: 2026-08-17

---

## 1. 背景与目标

### 1.1 问题

项目无自研梯子检测；攀爬由引擎完成：角色与 `TrussPart` 有效接触 → `HumanoidStateType.Climbing`。Animate 仅跟状态播 Climb。

**现象**：同一关卡、同一梯子，Walk 可流畅进攀爬，Run 常被顶开/打滑进不了 `Climbing`。

**根因**：Run 动画使可碰撞 Torso 相对 `HumanoidRootPart`（HRP）前倾更大 → Torso 先撞开梯子 → HRP 附近攀爬接触区够不着。不是 `WalkSpeed` / `SetStateEnabled(Climbing)` 问题。

### 1.2 目标

- 在 Run 接近梯子时，**提前**压低躯干前倾（视觉切 Walk 族），让引擎仍能触发原生 Climbing。
- 不改攀爬移动权威、不改 CMS WalkSpeed / Sprint 语义。

### 1.3 非目标（首版）

- 自定义攀爬 FSM / 贴墙移动
- 非 `TrussPart` 自定义梯子
- 长期关 Torso 碰撞
- 服务端权威攀爬
- 二期可选：沿法线短时速度钳制（须不 `PlatformStand`、不进 CharacterMotion Drive）

---

## 2. 方案摘要

| 项 | 结论 |
|----|------|
| 名称 | ClimbAssist / 攀爬接近辅助 |
| 权威 | 引擎 Humanoid Climbing |
| 手段 | HRP 多高度射线探测 + 地面 Run→Walk 视觉覆盖 + 空中抑制 AirLean |
| 落点 | `StarterCharacterScripts/Animate/ClimbAssist.luau` |
| 消费 | `GroundLocomotion`（地面）；`AirLean`（空中归零 lean）；`getGroundStable` 抑制时对 Strafe 返回 Walk |

```text
接近 Truss（地面 Run 或空中 Jump/Fall）
  → ClimbAssist 探测（HRP）
  → suppressRunLean
  → 地面：Walk 视觉 / 空中：AirLean reset
  → HRP 接触区贴上 Truss
  → 引擎 Climbing
```

---

## 3. 模块与边界

| 模块 | 职责 |
|------|------|
| `ClimbAssist` | 探测、滞回、意图门闩、抑制超时；输出只读状态（地面+空中） |
| `GroundLocomotion` | 地面消费 `suppressRunLean`：Run→Walk **视觉**覆盖 |
| `AirLean` | 空中消费：`suppressRunLean` 时 `isSuppressed`，瞬时归零程序 lean |
| `AnimateSetting.ClimbAssist` | 距离、法线、点积、fade、超时、空中速度意图等常量 |
| `init.client` | Heartbeat：先 `climbAssist.update`，再 `groundLoco.update` |

不经 `UtilsSystem`。不碰 CharacterControl / CMS / JumpPolicy / VelocityMotor（`PlatformStand` 期间 Assist 休眠）。

**R6 假设**：可碰撞 Torso 随动画前倾；本方案针对该几何。

---

## 4. 探测算法

每帧（抑制激活时建议每帧；空闲可每 2 帧）：

1. **门闩清除**：`PlatformStand` / loco suppress / Swimming / 已 Climbing / Physics·Ragdoll → 清空。**Jump/Freefall 不门闩**。
2. **原点**：HRP 位置 + 髋/胸两档垂直偏移，至少 2 条水平射线。
3. **射线方向**：优先水平 `MoveDirection`；无意图时可用 LookVector **仅更新** `nearClimbable`，**禁止**因此在地面置 `suppressRunLean`。
4. **距离**：进入 `PROBE_ENTER`、离开 `PROBE_EXIT`（滞回）。
5. **命中**：实例或祖先为 `TrussPart`，且 `|Normal.Y| < NORMAL_Y_MAX`；非 Truss 命中时沿射线短延伸二次查询。
6. **抑制条件**：
   - 地面：`MoveDirection · (-climbNormal) > APPROACH_DOT`
   - 空中：同上，**或**水平速度朝梯子推进（`AIR_VEL_INTENT_MIN`）
7. **超时**：地面 `MAX_SUPPRESS_SEC`；空中可用更长的 `AIR_MAX_SUPPRESS_SEC`。

对外状态：

```luau
{
  nearClimbable: boolean,
  climbNormal: Vector3?,
  suppressRunLean: boolean,
}
```

### 4.1 关卡约定（建议）

- 可攀结构使用 `TrussPart`（可透明）；装饰 Mesh 勿挡住 Truss 的 `CanQuery`，或接受二次穿透查询的短延距离。
- 勿把不可攀的竖向 Truss 装饰大面积贴在通道侧，以免假阳性（仍有点积/法线门闩）。

---

## 5. GroundLocomotion 注入点（定稿）

当 `suppressRunLean == true`：

1. `_applyStableLocomotionVisual`：若目标为 `Run`，改为播 **Walk 族**，fade 用 `SUPPRESS_FADE`（约 0～0.05s）。
2. **不**把权威 `_groundStable` 改成 Walk（StopRun / `RUN_DEMOTE_HOLD` / `_lastStopGait` 仍按真实跑态）；覆盖期间跳过 `_noteStopGait("Walk")`，避免污染停步选片。
3. `getGroundStable()`：抑制且权威为 Run 时对 Strafe **返回 `"Walk"`**，避免 ShiftLock 下仍叠 Run 方向轨前倾。
4. 若正处于 `StartRun`/`StartWalk`：取消衔接轨，短 fade 落到稳定视觉（权威稳定态仍按速度语义保留）。
5. 进入 Climbing 或探测 clear：立即停止覆盖，恢复正常 Run/Walk FSM。

不改 CMS `ExpectedWalkSpeed` / `Humanoid.WalkSpeed`。

## 6. 配置（`AnimateSetting.ClimbAssist`）

| 键 | 含义 | 初值建议 |
|----|------|----------|
| `ENABLE` | 总开关 | `true` |
| `PROBE_ENTER` | 进入邻近距离（studs） | `3.5` |
| `PROBE_EXIT` | 离开邻近距离 | `4.5` |
| `HIP_Y_OFFSET` / `CHEST_Y_OFFSET` | 射线高度相对 HRP | `0.5` / `1.2` |
| `NORMAL_Y_MAX` | 法线 \|Y\| 上限（剔顶面） | `0.35` |
| `APPROACH_DOT` | 朝梯子推进点积阈值 | `0.35` |
| `MOVE_INTENT_MIN` | 抑制所需最小 MoveDirection | 同 loco 意图量级 |
| `AIR_VEL_INTENT_MIN` | 空中水平速度意图阈值 | `2` |
| `DECOR_PENETRATE` | 装饰穿透延伸次数/步长 | `2` / `0.08` |
| `SUPPRESS_FADE` | 切入 Walk 视觉 fade | `0.05` |
| `MAX_SUPPRESS_SEC` | 地面最长抑制 | `0.45` |
| `AIR_MAX_SUPPRESS_SEC` | 空中最长抑制 | `0.9` |
| `PROBE_INTERVAL_SEC` | 非抑制时探测间隔（0=每帧） | `0` |

调参优先改本表，勿在业务里写死魔数。

## 7. 验收

- [ ] Run 冲向 Truss：稳定进 Climbing，无明显顶开打滑
- [ ] Walk 冲向：行为与现网一致
- [ ] 跳向/下落触碰梯子：空中即可进 Climbing，无需先落地
- [ ] 侧向经过梯子：不误抑制、不闪姿
- [ ] 面对梯子站立无输入：不切 Walk
- [ ] ShiftLock 空中接近：AirLean 被抑制，不因程序 lean 挤开
- [ ] ShiftLock 侧移接近：Strafe 为 Walk 族
- [ ] `PlatformStand` 技能位移中：不抑制、不报错
- [ ] 进 Climbing / 离梯落地：Climb 与 Run/Walk 恢复正确
- [ ] 抑制窗内脚滑可察觉但短时可接受

---

## 8. 并行建议（不阻塞）

长期减小 Run 动画躯干前倾；ClimbAssist 是运行时绷带，不能代替动画资产修正。
